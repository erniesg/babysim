# Officer Agent

The Officer Agent frames the experience as a probation intake and verdict.

## Owns

- Opening message
- Intake questions
- Ominous warning
- Verdict framing
- Officer expression

## Officers

- Officer Tan
- Officer Lim
- Officer Wong

## First Implementation

Use scripted text and optional pre-generated audio. The Three.js muppet prototype can replace the static officer after the core loop works.

## Required Fallback

If the muppet scene fails or is not integrated, render static officer text and continue the game.
